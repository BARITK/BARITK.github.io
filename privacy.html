Privacy Policy

Last updated: October 9, 2026

About this app

This is a private, personal application used only by its owner to connect their own Google Nest devices to a self-hosted Home Assistant instance. It is not offered to the public.

Data accessed

With the owner's permission, the app accesses Google Nest device data (such as doorbell events, camera streams and device status) through the Google Smart Device Management API.

How data is used

Data is used only to display and automate the owner's devices inside their own Home Assistant system. It stays on the owner's own server.

Data sharing

No data is sold, shared with third parties, or used for advertising. No data is collected or stored by any external service operated by this app.

Google API Services

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account permissions.
